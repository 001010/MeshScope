My Nodes

Radios you have connected to over USB are remembered by their node ID, not their COM port. Windows can assign a different COM number when you use another USB socket or hub, so MeshScope finds the radio by its USB serial number, then its last port, then by checking the node ID of each Meshtastic-looking port. If a connected My Node is unplugged, MeshScope reconnects it automatically when it is plugged back in, on whatever port it appears.

Message reach

Meshtastic floods each packet: every node that hears it rebroadcasts until the hop limit runs out. This simulates that flood over the radio links MeshScope has observed.

Terrain coverage heatmap

Predicts signal strength from real elevation data (hills, ridges and valleys block or shadow the signal), plus antenna height. A node's antenna height comes from its details panel if you set one there (rooftop, tower), otherwise from the altitude it reports compared with the terrain under it. Buildings and trees aren't in the elevation data, so they're approximated by the environment loss.

Shifts each node's prediction to match the SNR its neighbours actually measured, and widens the radius to include its farthest observed link.

Estimates only. Node positions may be shifted or rounded by their owners for privacy and security, so reach and heatmap results can be off. Not for surveying.

Addons

Addons are Python scripts that receive every inbound packet (from the radio, MQTT or the demo) and can log, alert, store data or act on it. Create one from a template, or import .py files or a .zip pack.

Addons run as normal Python on this PC with your permissions. Only enable code you trust. Imported addons start disabled.
